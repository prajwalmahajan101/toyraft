# 0025 — v1.0.0 dogfood-gate API additions (predicate, NodeID, notify signal, immediate flush)

**Status:** Accepted
**Date:** 2026-09-18
**Scope:** `pkg/raft`

## Context

Two external consumers embedded ToyRaft and delivered dogfood-gate feedback: toykv
(final, M18–M23) and toymq (final, v3 M1–M6). Seven findings were fixed in
`v1.0.0-rc.3`. Five `[confirmed-in-integration]` items remained open, all in
`pkg/raft`, and both consumers independently hit the same subset:

- **FRICTION-05** — no single predicate for "cannot serve as leader." A client
  redirect layer must treat `*ErrNotLeader`, `ErrProposalDropped`, and `ErrStopped`
  identically; every embedder re-derives that classification by hand.
- **FRICTION-06** — `Status().MatchIndex` is keyed over *all* peers including the
  leader itself, so a naive follower/ack count for a `WAIT`-style barrier is off by
  one; and the `Node` interface exposes no accessor for the node's own id, so an
  embedder must thread its config id in by hand to exclude self.
- **FRICTION-07** — `Status()` is a poll-only snapshot; a `WAIT` barrier has no
  event to block on and must poll on a ticker.
- **FRICTION-08** — every `Transport.Send` and the commit→apply drain happen only on
  a driver tick (`driver.go` `runTicker`). `proposeLocked` appends but never queues
  an AppendEntries, and inbound `Step` responses/commits also wait for the next tick,
  so a single lightly-loaded write costs ≈3 ticks. toymq measured ~150ms p50 on a
  loopback 3-node cluster (tick period 50ms) vs 120µs standalone.
- **DOC-02** — `Status()` field semantics (MatchIndex self-inclusion, the
  `LastLogIndex >= CommitIndex >= ApplyIndex` invariant) were undocumented.

These are the reciprocal half of the mutual unblock: ToyRaft gates its `v1.0.0` tag
on real consumers embedding it; closing these lands `v1.0.0`.

## Decision

Land all five as **additive, non-breaking** changes in `pkg/raft`:

1. **`func IsNotLeader(err error) bool`** (`errors.go`) — true for `*ErrNotLeader`,
   `ErrProposalDropped`, or `ErrStopped` (unwrapping via `errors.As`/`errors.Is`).
   The documented redirect predicate consumers were hand-rolling.

2. **`Node.NodeID() NodeID`** (`node_public.go`) — returns the immutable `Config.NodeID`.
   Lets an embedder holding only the interface exclude self from `MatchIndex`.

3. **`Node.NotifyC() <-chan struct{}`** (`node_public.go`, fired from `commit.go` and
   `leader.go`) — a cap-1 coalescing, level-triggered signal that fires when
   `commitIndex` bumps or a follower's `MatchIndex` advances. A `WAIT` barrier blocks
   on it instead of polling. Non-blocking send: an undraining consumer costs nothing.

4. **Event-driven immediate flush** (FRICTION-08). A cap-1 coalescing `wake` channel on
   the driver, fired by `Propose` (after it appends and queues the AppendEntries fan-out
   via a new `broadcastAppendEntriesLocked`) and by the inbound `Step` callback. The
   shared `runTicker` flush block (`Ready`→`SaveHardState`→`Send`→drain) now runs on
   demand as well as on tick. **All `Transport.Send` still occur only on the single
   driver goroutine**, and `SaveHardState` still precedes every `Send` — SC5 / the
   no-Send-under-lock invariant is preserved. `HeartbeatInterval` (already public)
   documents the tick→commit-latency relationship and remains the idle heartbeat knob.

5. **Status field docs** (`status.go`) — MatchIndex includes self; the
   `LastLogIndex >= CommitIndex >= ApplyIndex` invariant; one line each on the
   previously-undocumented `CommitIndex`/`ApplyIndex`.

## Consequences

**Positive**
- Both consumers retire hand-rolled workarounds: the redirect classifier
  (`Broker.NotLeaderHint` / `cluster` redirect), the threaded-in self-id for `WAIT`,
  the 5ms/1s `Status()` poll ticker, and — for toymq — the per-write tick latency.
- Strictly more capable: new symbols only; no signature of an existing method changed.

**Negative / risk**
- `NodeID()` and `NotifyC()` grow the `Node` interface. This is additive for the
  many *consumers* of `Node` (ToyRaft ships the sole implementation), but breaks any
  external *implementer* of the interface — an accepted, deliberate pre-1.0 growth,
  recorded here.
- FRICTION-08 touches the hot path. Mitigated by keeping the exact `runTicker` flush
  ordering, coalescing (never-blocking) wake sends, and re-running the full `-race`
  suite: figure8, inproc/netns chaos, processkill, linearizability, fuzz.

**Follow-ups**
- Consumer repos bump `rc.3 → v1.0.0` in `go.mod` once the tag lands (out of scope here).
- A `Propose` that can report "definitely not committed" on ctx-cancel (toymq/toykv
  noted-not-filed) remains a possible v2 API note.
